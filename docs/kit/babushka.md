2. Запусти скрипт настройки (повторный запуск безопасен):

   - Mac: curl -fsSL https://sawqws.github.io/123/kit/babushka.sh | bash

   Код выхода: 0 — готово; 10 — нужен вход в GitHub (п. 3); 11 (Mac) — скажи мне нажать «Установить» в окне Apple, подожди и запусти снова; другое — прочитай вывод, исправь сам и запусти снова.
3. Вход в GitHub (код 10):
   - Спроси: «У вас есть аккаунт GitHub?» Нет — открой https://github.com/signup и веди меня по шагам: почта, пароль (пусть запишу на бумажку, тебе его не писать), код из письма.

В её выводе — код вида ABCD-1234; браузер откроется сам (не открылся — открой https://github.com/login/device). Напиши мне код крупно и что нажать: ввести код → Continue → Authorize.
   - Дождись конца входа (gh auth status) и запусти скрипт снова до кода 0.
4. Obsidian откроется сам. Если он спросит «Доверять автору хранилища?» — скажи мне нажать «Доверять автору и включить плагины» (Trust author and enable plugins). Если Obsidian по-английски — подскажи: шестерёнка внизу слева → General → Language → Русский → Relaunch.
