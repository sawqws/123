# Задача: Claude Code с нуля + перенос старых наработок + система «второй мозг» (как у Глеба)

Ты — Claude Code на моём компьютере. Делай ВСЁ сам: команды, файлы, установка, проверка.
От меня — только вход в аккаунты (GitHub, Claude), коды подтверждения и «да», где спрашиваешь. Каждый такой шаг — одной фразой: что нажать.
Отчёт о том, что нашлось на компьютере: `~/claude-kit/scan.json` (хранилища Obsidian, git-репозитории, проекты без git, прошлый Claude, правила Cursor/Codex/Gemini). Начни с него.
**Главное: найти и перенести ВСЁ, до чего можно дотянуться** — каждое хранилище, репозиторий, проект, правило, скилл, MCP-сервер, историю прошлых чатов. Не спрашивай по каждому пункту: переноси сам, в конце дай список «перенесено / не получилось и почему».

Правила безопасности:
- Ничего не удаляй и не перемещай без моего «да». Перед любой перестройкой папок — копия (`~/claude-kit/backup-<дата>/`).
- Пароли, токены, ключи — никогда в git и не в чат. Секреты — в переменные пользователя (`setx ИМЯ значение` на Windows, `~/.zshrc` на Mac) или `.env` в `.gitignore`.
- Перед первым push любого репозитория сам проверь файлы на секреты (`.env`, `*.key`, `*.pem`, `token`, `password`, `api_key`, `sk-`, `ghp_` и т. п.) и вынеси найденное в `.gitignore`. Новые репозитории — только приватные. Спрашивай меня только если сомневаешься, личное ли это (сканы документов, фото).

## 4. Второй мозг (Obsidian + GitHub) — схема Карпатого, как у Глеба
- Хранилище: если есть живое хранилище Obsidian — оно и есть мозг (структуру не ломать, добавить только новые папки). Нет — создай `~/Documents/Brain` и открой его в Obsidian.
- Структура:
  - `raw/` — сырые заметки (моя территория): `raw/projects/`, `raw/notes/`, `raw/articles/`, `raw/images/`. Каждая заметка с фронтматтером `compiled: false`.
  - `wiki/` — пишет только Claude: `INDEX.md` (оглавление, читать первым), `projects/` (страница на проект: что это, статус, решения, следующие шаги), `concepts/` (статья на понятие). Связи — `[[wikilinks]]`.
  - `output/` — сохранённые ответы, промпты, отчёты.
  - `NOW.md` — живая передача между чатами (см. ниже).
- `.gitignore`: `.obsidian/workspace*.json`, `.obsidian/cache`, `.trash/`, `Thumbs.db`, `.DS_Store`, `.env`.
- git init (если ещё нет) → показать файлы → с моего «да» `gh repo create brain --private --source . --push` (ветка main).
- `CLAUDE.md` в корне хранилища — правила для любого Claude:
  - В начале каждого чата: `git pull`, прочитать `NOW.md`, затем `wiki/INDEX.md` и нужные страницы — и продолжать работу, не переспрашивая меня.
  - `NOW.md`: у каждого чата свой раздел «## <тема>» (над чем работаем, что сделано, в работе, дальше, что нужно от меня). Обновлять САМОМУ после каждого заметного шага, commit + push в main. Задача закончена — раздел удалить.
  - После любой правки — commit и push сразу в main.
  - Важное обо мне надолго (проекты, договорённости, привычки) — отдельной заметкой в `raw/` с `compiled: false`.
  - Наполнение: время от времени задавай мне по одному вопросу о проектах, учёбе, планах; ответ — заметкой в `raw/`.
  - Компиляция («скомпилируй мой мозг» или накопилось ~5 заметок): заметки `compiled: false` → страницы `wiki/projects/` и `wiki/concepts/`, связи `[[…]]`, обновить `INDEX.md` (описание и дата), в заметках поставить `compiled: true`. Раз в неделю — проверка: противоречия, заметки без связей, пробелы.
  - Если я пишу «121»: обновить `NOW.md`, запушить и выдать одним блоком кода сообщение для нового чата («Продолжаем. Подключи репозиторий brain и прочитай NOW.md.» + 2–4 строки сути).
  - Паролей и секретов в репозиторий не писать.
- Перенеси в мозг старые наработки (оригиналы не трогай):
  - правила и знания из старых `CLAUDE.md`, `~/.claude/CLAUDE.md`, `AGENTS.md`, `.cursorrules`, `~/.cursor`, `~/.codex`, `~/.gemini` (`ai_rules`, `ai_dirs`) — заметками в `raw/notes/` (что было, откуда);
  - история прошлых чатов Claude Code (`~/.claude/projects/*/*.jsonl`): пройди по ним (агентами параллельно, если много) и вынеси главное — проекты, решения, договорённости, что не доделано — в `raw/projects/` и `raw/notes/`;
  - другие хранилища Obsidian (если их несколько) — подключи как отдельные приватные репозитории или, если они мелкие, — папкой в мозг (решай по смыслу, ничего не удаляя). Сразу сделай первую компиляцию → `wiki/INDEX.md` и страницы проектов по найденным репозиториям.

## 5. Глобальные правила Claude (на все проекты) — `~/.claude/CLAUDE.md`

Подставь реальный путь. Скиллы, агенты и команды прошлого Claude (`~/.claude/skills|agents|commands`) — оставь на месте; если они лежали в другом месте (старый профиль, репозиторий) — скопируй в `~/.claude/`.
