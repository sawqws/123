# Общее для всех ботов (`common/`): вид, аватары, поддержка, медиа, мини-приложения, режим

> Справка Claude по этой папке (загружается сама при работе с её файлами). Общие правила — в корневом CLAUDE.md.

- Вид всех мини-приложений — «Оникс-стекло» (Глеб утвердил 14.10: вариант 6+7 «А»): чёрный фон с тёплыми золотыми пятнами, всё — тёмное стекло как в iOS 26 (полупрозрачные карточки, кнопки, вкладки с бликом), золото, шрифт iPhone SF Pro (`--round` = -apple-system) везде, крупные скругления (карточки 32 px, кнопки/вкладки — капсулы). Слой `common/webapp/onyx.css` дописывается в конец `common/webapp/kit.css` (`kit.css`/`kit.js` в папках `*/webapp/` — ссылки на common), для Студии (botkit) и Ловца — `studio/kit/onyx.css`. Править только onyx.css, затем `python3 common/sync_kit.py` (повторный запуск заменяет слой). Фон держит `html`, `body` прозрачный (иначе пятна за стеклом прячутся). Токены: `--bg #070708`, `--card` (стекло), `--ink #f6f1e7`, `--gold`/`--gold-ink`, `--blur`, `--hl`; у бота свой только `--accent` → `--accent-soft/-pastel/-line` (полупрозрачные), `--accent-deep` (светлый тон для текста). Главная кнопка у всех — золотое стекло. kit.js всегда `data-scheme="dark"`, шапка Telegram — `--bg`. Варианты, из которых выбирали: https://claude.ai/artifact/WPKPhJAfKh7JFidPPjkq1Q. Скриншоты без сервера: `node common/webapp/shots.js <webapp> <примеры.json> <префикс>`.
- Аватары ботов (вид в Telegram, «Оникс-стекло»): `common/avatar.py` — почти чёрный фон с мягким свечением цвета бота (`glow` в `BOTS`), стеклянный диск с бликом и золотой векторный знак (без эмодзи и шрифтов). `preview <out.png>` — лист всех, `make <бот> <out.png>`, `apply [бот…] [--dry-run]` — на сервере ставит аватары через Bot API `setMyProfilePhoto` (токены из /etc/*-bot.env, нет env — пропуск; боты Студии из `/root/bots/registry.json` — заодно `data/avatar.png`, его держит botkit). Новые боты Студии — `studio/avatar.py` (обёртка: цвета плана → свечение, золотая буква, скруглённая как SF Rounded). Аватар и баннер Секретаря — `tgbot/art/make.py` (тот же генератор). Тесты: `python3 common/test_avatar.py`.
- 🛠 Поддержка во всех ботах (`common/support.py`): `/fix` (в меню команд добавляется сам) или кнопка `sup|ask` → Глеб пишет ошибку или доработку (текст, голос, скриншоты) → Claude Code правит код этого бота (видит последние логи pm2), гоняет его тесты (упали — ещё попытка, иначе правка откатывается), локальный коммит в /root/horo (или в папке бота Студии), перезапуск pm2; «↩️ Откатить» — git revert. Одна задача на сервер за раз (flock `/tmp/horo-support.lock`). «Правка» = изменения только в папках бота и не в `data/`/`tmp/` (`Support.pathspec`), иначе живые данные других ботов попадали в коммит и каждая просьба заканчивалась ложным «готово». Подключено: HDP, Планер (только владелец), Тренер, КПП, Глаз, Авито, Секретарь (режим own), Студия и все её боты (botkit). В Главном свой `/fix` — «доработать любого». Тесты: `python3 common/test_support.py`.
- 🛠 «Поддержка и пожелания» видна везде одинаково: в чате — кнопка «🛠 Поддержка» (`sup|ask`) в главном меню каждого бота (HDP — в «⚙️ Ещё», Студия и её боты — на главном экране через botkit, Секретарь — в «Аккаунте»; в Главном и у Секретаря-в-Главном — `fix|…` → «Доработать» с выбором бота); в мини-приложениях — строка `Kit.supportRow(путь)` → лист `Kit.support` (текст + скриншот, `common/webapp/kit.js`) → `POST …/api/support` → `SUP.web(uid, body)` (тот же Claude, что /fix; только владелец по initData). Главный: `/app/api/support` {bot, text, photo} → `maker.fix`; Секретарь в Главном шлёт туда же; Студия — встроенный `api("support")` в botkit + строка в её kit.js.
- Голосовые и фото во всех ботах: `common/media.py` (kind, voice_text, photo_path), распознавание `common/voice.py` (faster-whisper в `common/.venv`, ставит `common/setup.sh`).
- Мини-приложения у всех ботов (чат с кнопками остаётся полностью рабочим, приложение — второй вариант): Студия `studio/webapp` (`apps.<host>` → 8795), HDP `bot/webapp`, Планер `planner/webapp`, Тренер `coach/webapp`, Глаз `eye/webapp`, Главный `hub/webapp` (`/app`, `hub.<host>` → 8790), КПП `kpp/webapp` (`kpp.<host>` → 8792), Авито `avito/webapp` (`avito.<host>` → 8793), Секретарь `tgbot/webapp` + `tgbot/web.py` (`agent.<host>` → 8794). Все https-адреса раздаёт Caddy планера (`planner/planner.py` → `caddyfile`), `<host>` = `<ip-через-дефисы>.sslip.io`; доступ — только владельцу по подписи Telegram initData. Общий стиль чата: жирный заголовок с одним эмодзи, содержимое в `<blockquote>` (длинное — expandable), второстепенное `<i>…</i>`, ошибки «⚠️ …», кнопки ≤ 24 символов и ≤ 3 в ряд, колонки не выравнивать пробелами; цветные кнопки (`style`) с откатом без цвета при 400.
- Режим «💬 Чат / 📱 Приложение» у всех ботов: при первом /start карточка «Как удобнее?» (💬 В чате / 📱 Приложение), дальше /mode, кнопка «⚙️ Режим» в меню и строка «💬 Перейти в чат» в настройках мини-приложения (`POST /api/mode {mode}` → в чат приходит главное меню, приложение закрывается). «Чат» — всё кнопками в чате, web_app-кнопок в сообщениях нет (кроме явного /app; кнопка меню слева от поля ввода остаётся); «приложение» — /start короткий: главная кнопка открыть приложение + 2–3 действия, команды и текст работают всё равно. В /start подпись «Режим: 💬 чат / 📱 приложение». HDP хранит в `settings.json` (`mode`, клавиатура у поля ввода меняется по режиму), Планер — в `db.meta("mode")` (в режиме чата — меню кнопками `v|…`, пояс через `/tz`). Тренер — `db.meta("mode:<uid>")` (в режиме чата — главное меню кнопками, «📄 Полностью» шлёт текст в чат, `/profile` меняется словами; кнопка «Перейти в чат» — в «Сегодня» и в профиле); Глаз — `setting("mode")` (в режиме чата — меню с «👁 Что видел» и «⚙️ Режим», «Перейти в чат» — на вкладке «Разговор»).
  - Режим в КПП и Авито: `st["mode"]` (`data/state.json`), те же `ui_mode`/`set_mode`/`MODES`, карточка «🧭 Как удобнее?», кнопки `mode:chat`/`mode:app` (карточка → «✅ Режим: …», следом главный экран), «⚙️ Режим» (`mode`) в главном меню, `app_buttons(always=True)` только для /app, в приложении строка «💬 Перейти в чат» под «Поддержкой» (КПП — на главном экране и экране входа, Авито — во вкладках «Объявление» и «Все»; `chatRow()` в `app.js`); `/api/state` отдаёт `mode`; тесты — классы `Mode` в `kpp/test_kpp.py` и `avito/test_avito.py`.
- Проверка сайтов перед выкаткой (Глеб 29.10): `node common/devcheck.js <url> [папка] [--scheme light]` — 11 размеров от Android 360 до монитора 2560, находит прокрутку вбок, вылезание за экран, мелкие кнопки и текст, ошибки консоли, снимает скриншоты; `node common/perfcheck.js <url>` — плавность при CPU ×4 (загрузка и прокрутка).
