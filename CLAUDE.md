- Это только для только что поставленного/созданного бота; обход всех ботов разом — по-прежнему только по просьбе Глеба (см. ниже).
- Если бот повторяет известное приложение (Форма = WHOOP) — сверка со скриншотами оригинала бок о бок после каждой правки вида.

## Как делать задание по ссылке

1. `node horo/fetch.js <ссылка>`: условие, вопросы, варианты, прошлые попытки и комментарии учителя. Только чтение, попытку не тратит. Картинки сохраняются в `horo/tmp/<task>/`, их нужно посмотреть через Read.
2. Решить и записать ответы в `horo/tmp/<task>/answers.json` (формат в шапке `horo/submit.js`).
3. `node horo/submit.js <ссылка> horo/tmp/<task>/answers.json`: создаёт попытку, вводит ответы, отправляет и печатает результат.
4. Ответить пользователю: результат и что было написано.

Если пользователь просит только показать ответы, шаг 3 не делать.

## Правила сайта (проверено)

- Попытку создаёт кнопка «Начать» на странице задания. Открытие ссылки `/questions/...` у начатого теста не тратит попытку, но **не открывать вопросы зря**: попыток обычно 3.
- Правильные ответы после сдачи не показываются, видно только число баллов. Если ответ неоднозначный, а попытка последняя, сначала спросить пользователя.
- Сравнение строгое, по строке. Если стоит «регистр важен», регистр учитывается.
- Предложения (испанский, «ordena frases»): первая буква заглавная, **без точки в конце**. Запятые как в обычной орфографии.
- Пропуски в тексте: вводить только пропущенное слово или форму, без лишних слов. Даже если дан «список слов», ставить их **в той форме, которую требует предложение** (биология: «радиальную», «стрекательных», «эктодермы» вместо «радиальная», «стрекательные», «эктодерма» — так засчитали). Ответ «nunca ha montado» не засчитали, засчитали «ha montado».
- Математика: десятичные дроби **через запятую** (`-24,5`, `0,36`), минус обычным дефисом.
- Задания `detailedAnswer` (решение на фото, конспект, устный ответ) учитель проверяет вручную. По умолчанию не отправлять, а показать текст пользователю. Отправлять только если пользователь просит: `node horo/answer.js [--replace] <ссылка> answer.txt [файлы...]` (файлы прикрепляются по одному, после отправки проверяется, что дошли все, иначе ошибка; счётчик загрузок — только `horodigital.ru/store/t/upload`, без Яндекс-метрики. **Никогда не запускать answer.js «на пробу»** — он реально отправляет ответ учителю; для проверки состояния — только `fetch.js`) (каждая строка — абзац; файлы прикрепляются через кнопку-скрепку; `--replace` удаляет свой непроверенный ответ перед отправкой). Сайт сам хранит черновик поля ответа (`/api/drafts/v1/studentMessage/<progress>_v2`) — после отправки в нём оставались те же текст и файлы («вторая попытка, не отправлено»); `answer.js` после отправки чистит его (`clearDraft` в `lib.js`) и печатает «Поле ответа на сайте: пустое». Текст учителю — только если задание просит ответ словами; если ответ на картинках — без текста и комментариев (`NO_COMMENT` в `bot/bot.py`, Глеб 15.10).
- Решение «от руки» (вариант 3, Глеб выбрал 14.10): `node horo/shot.js <ссылка> shot.png` → `horo/sheet.py` (`Work`, `solve`, `save`): на скрине справа от примера — только ответ, решение — на тёмном листе в клетку. Математика — «живая рука» `Hand(exact=False)` (Глеб: «математику не трогай» — не менять); текст и таблицы — ровная азбука `horo/fonts/gleb_norm.npz` (утверждена 15.10, не менять без его просьбы). Только методы 8 класса (`GRADE8`), перепроверка `verify`. Не писать «ОДЗ» — «при x = … знаменатель = 0». Перед отправкой показать картинку Глебу; переписанную таблицу/лист — ждать его «да». **Всё подробно (почерк, алфавит, штампы, пересборка азбуки, тесты) — `horo/CLAUDE.md`: прочитать перед любой работой с почерком.**
- Таблица в условии («заполни таблицу», картинка с пустыми клетками): заполнять его почерком прямо на картинке, а не текстом — `horo/table.py` (`Table(картинка)`: клетки находит сам по линиям, таблица может продолжаться на следующей картинке; `print(t)` — сетка, `write(строка, столбец, текст)` — по словам и с уменьшением, чтобы влезло; `save`). Каждая картинка таблицы — отдельным файлом в `draft_files/`, в draft.txt — только ответы на вопросы вне таблицы. Без «ё», «», длинного тире. Промпт — в `HANDWRITE`. Тесты: `python3 -m unittest horo/test_table.py`.
- Доработка (статус `reworking`/`failed`, учитель написал, что доделать, например «Решить № 3-4»): `fetch.js` сохраняет файлы прошлых ответов (`prev<N>_<k>.jpg` — его фото тетради/скрины) и пометки учителя (`mark<N>_<k>`) — посмотреть их, понять, что уже сделано, и сделать **только** то, что просит учитель. Письменное решение — через `sheet.Work` (только эти номера: ответы на скрине, решение на листе) → черновик учителю (бот показывает, Глеб жмёт «Отправить»). Промпты — `HANDWRITE` и `REWORK` в `bot/bot.py`.
- Рабочие листы (PDF во вкладке «Файлы» задания, путь в task.json → files[].location): скачать, `pdftoppm -r 144`, координаты пустых строк — `pdftotext -bbox-layout`, вписать ответы рукописным шрифтом (пример: заполнение листа по экономике, шрифт Caveat), прикрепить картинки. Писать как ученик 8 класса: кратко, без таблиц.
- Открытие страницы `detailedAnswer` в браузере помечает комментарии учителя как прочитанные. `fetch.js` берёт их через API, без этого побочного эффекта.

## Техническое

- Облачная среда: HTTPS через прокси со своим CA. `horo/lib.js` сам подключает его в Chromium по SPKI.
- Сессия браузера сохраняется в `horo/tmp/state.json` (в .gitignore). При истечении скрипт сам войдёт заново.
- Типы вопросов, которые умеет `submit.js`: `manualInput`, `blanks` (выпадающие списки и поля), `sequence` (порядок), `singleMatching` (пары), `grouping` (группы), `singleSelection` и `multipleSelection` (по uuid варианта; ставит и снимает отметки, проверено на истории «7. Северная война - фактчек»).
- **Устройство каждого бота — в `<папка>/CLAUDE.md`** (`bot/`, `hub/`, `tgbot/`, `coach/`, `common/`, `studio/`, `planner/`, `kpp/`, `avito/`, `eye/`, `catcher/`, `pulse/`, `site/`; почерк — `horo/`): пути, pm2-имена, секреты `/etc/*.env`, установка, тесты, решения Глеба по виду. Claude Code подгружает такой файл сам, когда работает с файлами папки; если задача про бота, а его файлы ещё не открывались, — сначала прочитать его `CLAUDE.md`. Кратко:
  - HDP (`bot/`, тесты `python3 bot/test_bot.py`): тест через бота (`HORO_DEFER`, сдача по таймеру, `RETRY`), задержка ответа учителю (`HDP_SEND_DELAY`, «⏳ Отправка»), установка `bot/install.sh`, приложение, сайт-зеркало `hdp.<host>`, «⏳ Ожидание», «🎯 Подтверждения», «📖 Подготовка», медиа, до 3 заданий сразу, черновики учителю.
