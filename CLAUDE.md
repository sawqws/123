# Задания на horodigital.ru

Логин и пароль лежат в переменных окружения `HORO_LOGIN` и `HORO_PASSWORD`. Не выводить их и не коммитить.

## Как делать задание по ссылке

1. `node horo/fetch.js <ссылка>`: условие, вопросы, варианты, прошлые попытки и комментарии учителя. Только чтение, попытку не тратит. Картинки сохраняются в `horo/tmp/<task>/`, их нужно посмотреть через Read.
2. Решить и записать ответы в `horo/tmp/<task>/answers.json` (формат в шапке `horo/submit.js`).
3. `node horo/submit.js <ссылка> horo/tmp/<task>/answers.json`: создаёт попытку, вводит ответы, отправляет и печатает результат.
4. Ответить пользователю: результат и что было написано.

Если пользователь просит только показать ответы, шаг 3 не делать.

## Правила сайта (проверено)

- Попытку создаёт кнопка «Начать» на странице задания. Открытие ссылки `/questions/...` у начатого теста не тратит попытку, но **не открывать вопросы зря**: попыток обычно 3.
- Правильные ответы после сдачи не показываются, видно только число баллов. Если ответ неоднозначный, а попытка последняя, сначала спросить пользователя.
- Сравнение строгое, по строке. Если стоит «регистр важен», регистр учитывается.
- Предложения (испанский, «ordena frases»): первая буква заглавная, **без точки в конце**. Запятые как в обычной орфографии.
- Пропуски в тексте: вводить только пропущенное слово или форму, без лишних слов. Даже если дан «список слов», ставить их **в той форме, которую требует предложение** (биология: «радиальную», «стрекательных», «эктодермы» вместо «радиальная», «стрекательные», «эктодерма» — так засчитали). Ответ «nunca ha montado» не засчитали, засчитали «ha montado».
- Математика: десятичные дроби **через запятую** (`-24,5`, `0,36`), минус обычным дефисом.
- Задания `detailedAnswer` (решение на фото, конспект, устный ответ) учитель проверяет вручную. По умолчанию не отправлять, а показать текст пользователю. Отправлять только если пользователь просит: `node horo/answer.js [--replace] <ссылка> answer.txt [файлы...]` (каждая строка — абзац; файлы прикрепляются через кнопку-скрепку; `--replace` удаляет свой непроверенный ответ перед отправкой).
- Решение «от руки» на скриншоте задания (как пишет Глеб на iPad): `node horo/shot.js <ссылка> shot.png` (тёмная тема, 2x), затем `horo/hand.py` (класс Hand: text, expr с дробями, circle). Почерк: в первую очередь его **настоящие буквы**, вырезанные с его скриншотов (`horo/fonts/gleb.npz`: a b m n p q x 0–2 4–8 + − = ², по 1–9 вариантов, без искусственных неровностей); чего нет в наборе — нарисованные похоже (GLYPHS) или скелет Neucha. Если пришлёт алфавит — дополнить набор из него. В заметках iPad цвет (90,160,240) и width≈5. Писать как он: в основном математика (цепочка «= дробь = дробь»), слов минимум. Обводить номера решаемых пунктов. Не писать «ОДЗ» — вместо этого «при x = … знаменатель = 0». Перед отправкой показывать картинку пользователю.
- Рабочие листы (PDF во вкладке «Файлы» задания, путь в task.json → files[].location): скачать, `pdftoppm -r 144`, координаты пустых строк — `pdftotext -bbox-layout`, вписать ответы рукописным шрифтом (пример: заполнение листа по экономике, шрифт Caveat), прикрепить картинки. Писать как ученик 8 класса: кратко, без таблиц.
- Открытие страницы `detailedAnswer` в браузере помечает комментарии учителя как прочитанные. `fetch.js` берёт их через API, без этого побочного эффекта.

## Техническое

- Облачная среда: HTTPS через прокси со своим CA. `horo/lib.js` сам подключает его в Chromium по SPKI.
- Сессия браузера сохраняется в `horo/tmp/state.json` (в .gitignore). При истечении скрипт сам войдёт заново.
- Типы вопросов, которые умеет `submit.js`: `manualInput`, `blanks` (выпадающие списки и поля), `sequence` (порядок), `singleMatching` (пары), `grouping` (группы), `singleSelection` и `multipleSelection` (по uuid варианта; ставит и снимает отметки, проверено на истории «7. Северная война - фактчек»).
- Если попытка уже начата («Продолжить»), в ней могут быть чужие выбранные ответы: `submit.js` их перезаписывает.
- Ширина пустого поля в `blanks` (`style="width: Npx"` в task.json) пропорциональна длине ответа учителя, примерно 7 px на символ. По ней можно отличить «couldn't» от «could not».
- Бот: установка на новый сервер одной командой `curl -fsSL https://raw.githubusercontent.com/sawqws/123/claude/fervent-turing-gcfdu9/bot/install.sh | bash` (pm2, секреты в /etc/horo-bot.env, владелец — первый /start). Токены и пароли в репозиторий не класть: он публичный.
- Английский: апостроф прямой `'` засчитывался (тесты 2.10, 2.12, 2.17).
