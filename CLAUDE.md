# Второй мозг (схема Karpathy: raw → LLM → wiki)

В начале любой работы с базой: прочитай `wiki/INDEX.md`, затем найди в `raw/` заметки с `compiled: false` или без фронтматтера.

## Структура

- `raw/` — территория человека. LLM не редактирует содержимое, только меняет флаг `compiled`.
  - `projects/` — материалы про проекты и работу
  - `articles/` — веб-статьи, PDF
  - `notes/` — идеи, черновики, ответы из интервью
  - `images/` — картинки (локально)
- `wiki/` — пишет только LLM.
  - `INDEX.md` — оглавление с кратким описанием каждой страницы
  - `projects/` — одна «живая» страница на проект: что это, статус, решения, следующие шаги
  - `concepts/` — одна «вечная» статья на концепт: что говорит raw/ + синтез
- `output/` — сохранённые ответы, слайды, графики.

Каждая заметка в `raw/` начинается с фронтматтера:

```yaml
---
compiled: false
---
```

## Правила компилятора (команда «скомпилируй мозг / wiki»)

1. Прочитай `wiki/INDEX.md`, найди в `raw/` все заметки с `compiled: false`; заметки без фронтматтера тоже считай необработанными. Обрабатывай только их.
2. Определи проекты и ключевые концепты.
3. Проекты → создай/обнови страницы в `wiki/projects/`. Концепты → по одной статье в `wiki/concepts/`.
4. Связывай статьи через `[[wikilinks]]` — связи важнее самих статей.
5. Обнови `wiki/INDEX.md` (краткое описание каждой страницы, дата компиляции).
6. В обработанных заметках `raw/` поставь `compiled: true`.
7. Ответы на вопросы по базе сохраняй в `output/`, ценные выводы — обратно в `wiki/`.

## Health check (раз в неделю, команда «health check»)

Найди противоречия между статьями, изолированные страницы без связей, пробелы в темах; предложи, что скомпилировать дальше. После — снова компиляция.

## Наполнение (интервью)

Задавай вопросы о проектах, работе и жизни по одному. Каждый содержательный ответ — отдельная заметка: про конкретный проект → `raw/projects/`, остальное → `raw/notes/`, с `compiled: false`. После ~5 заметок предложи компиляцию.
