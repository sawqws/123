# «Глаз» — Claude в очках Ray-Ban Meta

Telegram-бот + страница разговора. Фото с очков → Claude узнаёт, что это, и говорит вслух.
Разговор голосом без рук: очки подключены к iPhone как Bluetooth-гарнитура, поэтому микрофон и
звук — очки (их динамики). AirPods не нужны.

## Как пользоваться
1. Сфоткал очками → приложение Meta AI импортирует фото в «Фото» на iPhone
   (в настройках Meta AI — автоимпорт и сохранение в «Фото»; точные названия пунктов не проверены).
2. Фото → боту в чат (можно с вопросом в подписи) или «📷 Фото» на странице «Глаз».
   Claude отвечает: что это (здание, вещь, вывеска, еда), коротко и вслух.
3. Кнопка «Глаз» слева от поля ввода → «🎙 Говорить». Дальше без рук: говоришь — слушает,
   замолчал на секунду — отвечает голосом. Разбор новых фото звучит там же.
   Если в Telegram микрофон не включается — `/link`, та же страница в Safari («На экран „Домой“»).
4. Где ты, бот знает по GPS телефона (страница спрашивает разрешение) — адрес помогает узнать здание.
   В чате — 📎 → Геопозиция.

Команды: `/app`, `/link` (личная ссылка для Safari), `/new` (разговор заново), `/status` (проверка).

## Как устроено
- `eye.py` — бот (стандартная библиотека), веб-сервер 127.0.0.1:8791, https `eye.<ip-через-дефисы>.sslip.io`
  (Caddy планера, иначе свой). Страница пускает по подписи Telegram или по ключу из `/link` (HMAC от токена).
- `webapp/` — страница: свой детектор речи (громкость, 0,9 с тишины — конец фразы) → WAV 16 кГц → `/api/talk`;
  ответ играет через AudioContext (на iPhone работает после первого нажатия). Экран не гаснет (Wake Lock).
- `ai.py` — `claude -p`: фото — модель по умолчанию (`EYE_MODEL`), разговор — `haiku` (`EYE_TALK_MODEL`), быстрее.
  Контекст: последние 3 фото за 3 часа с разбором, место, последние 12 реплик (после 2 ч тишины — заново).
- `speech.py` — распознавание: `stt_worker.py` (faster-whisper из `common/.venv`), модель держится в памяти,
  пока идёт разговор, выгружается через 10 мин. Озвучка — edge-tts (`EYE_VOICE`, по умолчанию ru-RU-DmitryNeural);
  нет её — читает голос iPhone.
- `photos.py` — JPEG до 1600 px, GPS из EXIF, адрес по координатам (OpenStreetMap Nominatim).
- Данные: `eye/data/` (фото, история, вне git). Секреты: `/etc/eye-bot.env` (`EYE_TOKEN`, `EYE_ALLOWED`, `EYE_URL`).

Замеры (облако Claude, 2026-10-11): ответ в разговоре ~5–6 с (haiku), разбор фото ~9–12 с,
распознавание фразы ~1 с (первая — дольше, модель грузится при открытии страницы), озвучка 0,5–4 с.

## Установка
В «Главном»: `/eye` → «🤖 Создать бота сам» (Секретарь сам создаст бота в @BotFather) —
или пришли токен. Вручную: `curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/eye/install.sh | bash`.

Тесты: `python3 eye/test_eye.py`.

## Ограничения
- Страница должна быть открыта на экране: iOS не даёт сайтам слушать микрофон в фоне или на заблокированном экране.
- Фото попадают к боту через «Фото» (или прямо из приложения Meta AI «Поделиться» → Telegram).
  Камеру очков напрямую даёт только Meta Wearables Device Access Toolkit — нужно своё iOS-приложение (Mac + Xcode).
