# 📡 Пульс — все чаты Claude Code на одном экране

Глеб держит несколько чатов Claude Code сразу. Пульс показывает по каждому: насколько заполнен контекст,
сколько задач плана сделано по его последнему запросу, что чат делает прямо сейчас, закончил ли, ждёт ли ответа.

```
облачная сессия ── pulse/reporter.py ──POST /api/pulse (ключ входа Claude)──▶ Главный (hub.py)
                                                                              │ 127.0.0.1:8799
                                                                              ▼
                              Telegram ◀── pulse.py (живая карточка, уведомления, мини-приложение pulse.<host>)
```

- **reporter.py** — запускается первой командой в каждом чате (`start`, повторно — ничего), читает журнал сессии
  `~/.claude/projects/*/<CLAUDE_CODE_SESSION_ID>.jsonl` с места, где остановился, раз в 4 с; шлёт сводку при
  изменении и раз в минуту «жив». Название — `ai-title`, ссылка — `remote_session_change`, контекст — `usage`
  последнего ответа, план — результаты TaskCreate/TaskUpdate (и старый TodoWrite), статус — `end_turn` /
  незакрытый `AskUserQuestion`. `once` — показать сводку без отправки.
- **pulse.py** — бот. `/start` — живая карточка (правится сама), кнопка чата → подробно (запрос, план ✅/▸/○,
  сейчас, шаги/файлы/коммиты/PR, последний ответ, «↗️ Открыть чат»). Уведомления: закончил, вопрос, контекст
  60/80/90%, пропала связь (выкл. по умолчанию) — `/alerts`. Скрыть чат — до его новой активности.
- **Окно контекста**: облако сжимает контекст на 80% окна, по первому сжатию бот узнаёт окно модели
  (`windows` в state.json). До этого — 200 тыс., а если чат ушёл дальше 168 тыс. без сжатия — 1 млн; такие
  проценты помечены «≈».
- Данные — `pulse/data/state.json` (вне git). Тесты: `python3 pulse/test_pulse.py`.
