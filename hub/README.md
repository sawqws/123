# Главный — бот, который следит за ботами

Один бот для всего сервера: видно, кто работает, кто упал, и всё чинится кнопками.

- **Боты** (/bots): 🟢/🔴 у каждого, сколько работает и сколько памяти; карточка бота — «Перезапустить» и «Логи».
- **Сам пишет**, если бот упал (2 проверки подряд), перезапускается по кругу (+3 за 10 минут) и когда заработал снова.
- **Обновить всех** (/update): свежий код из main, `npm install` при изменениях, перезапуск всех ботов.
- **Поставить**: тренер WHOOP, планер, КПП — по токену от @BotFather (сообщение с токеном удаляется).
- **Сервер** (/server): память, диск, нагрузка; тревога, если диска меньше 10 % или памяти меньше 7 %.
- **/paid 07.11** — срок оплаты сервера, напоминание за 7, 3 и 1 день.
- **📂 Все боты** (/all): все боты со ссылками «▶️ Начать», кто не поставлен — «➕ Поставить», как собрать их в папку «Боты». Один раз приходит сам после обновления.
- **🛠 Сделать бота** (/make): ТЗ текстом, голосовым, со скриншотами → Claude Code на сервере придумывает имя и пишет код в `/root/bots/<slug>/` (свой git) → бот создаётся в @BotFather через Секретаря (`tg.py newbot`, Глеб жмёт «Да») или Глеб присылает токен сам → pm2 `bot-<slug>` (токен в `.env`, 600). Потом «✏️ Правки», «🗑 Удалить».
- **✏️ Доработать** (/fix): любой бот + что поменять → Claude правит код, гоняет тесты, коммитит → перезапуск; «↩️ Откатить» — `git revert`. Правки ботов из репозитория — локальные коммиты в `/root/horo`: «Обновить всех» переносит их поверх main (rebase; при конфликте — кнопка «Сбросить локальные правки»). Свободный текст или голосовое без команды — «сделать нового или доработать какого?». Одна задача Claude за раз.
- **Отбивка и напоминания** (`hub/digest.py`): каждый вечер (по умолчанию 21:00, `/digest 21:00|off`) — какие боты работают, память/диск, оплата, напоминания на сегодня и завтра. `/remind 09:00 текст`, `/remind пн-пт 18:30 текст`, `/remind 25.10 10:00 текст`, `/reminders`.
- **Голосовые и фото** — во всех ботах через `common/media.py` (faster-whisper в `common/.venv`, ставит `common/setup.sh`; «Обновить всех» ставит его сам один раз).

- **Вход для Claude** (/claude): Claude из облачной сессии по https с ключом смотрит ботов и логи, перезапускает, обновляет и выполняет команды на сервере (`hub/remote.py`). Выключен, пока владелец не нажмёт «Включить»; о каждой команде Главный пишет в чат; «⛔ Выключить» и «♻️ Новый ключ» — в любой момент; 20 неверных ключей за час — вход закрыт на час. Адрес `https://hub.<ip-через-дефисы>.sslip.io` держит Caddy планера.

Проверка раз в минуту через `pm2 jlist`. Данные — `hub/data/state.json`. Только стандартная библиотека Python.

**Установка** (от root; заодно можно поставить тренера):
```
curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/hub/install.sh | HUB_TOKEN=123:ABC COACH_TOKEN=456:DEF bash
```
Потом /start в боте — станешь владельцем. Логи: `pm2 logs hub-bot`.

**Тесты**: `python3 hub/test_hub.py`, `python3 hub/test_maker.py`, `python3 hub/test_digest.py`.
