# Сайт «Ритм» (`site/`)

> Справка Claude по этой папке (загружается сама при работе с её файлами). Общие правила — в корневом CLAUDE.md.

- Сайт «Ритм» (привычки в стиле Grit + задачи/цели): исходник `site/ritm.html` (формат артефакта claude.ai, опубликован как https://claude.ai/artifact/Azqh8eJWCmDpzh3X3M54t5, данные в db-хранилище аккаунта). Версия-приложение для iPad (PWA, «На экран Домой»): `python3 site/build_pwa.py` собирает `docs/` (манифест, иконки, офлайн sw.js), публикуется на https://sawqws.github.io/123/ (GitHub Pages из ветки `gh-pages`; её сам обновляет workflow `.github/workflows/pages.yml` при изменении `docs/` в main); там данные в localStorage устройства, копия — «Итоги → Данные». После правки `site/ritm.html` пересобрать `docs/` и переопубликовать артефакт.
- Сайт «Калории» (счётчик КБЖУ + соль, Глеб 25.10: «как iPhone, минимализм, люкс»): `docs/kcal/` (один `index.html` + манифест, офлайн `sw.js` со своей областью `kcal/`), публикуется тем же workflow на https://sawqws.github.io/123/kcal/. Данные — localStorage устройства (копия — «Настройки → Данные»). Вид — Liquid Glass iOS 27 (Глеб 25.10: «в стиле самого последнего обновления Apple»): стекло только у навигации поверх контента (`.glass`: матовое, тёмный край, блик сверху; плавающее меню-капсула + круг «+», сжимается при прокрутке и раскрывается по нажатию; кнопки-круги в листах; низкие листы — стеклянные с отступом от краёв), контент непрозрачный; чёрный фон, белое кольцо калорий, неделя мини-кольцами, серия дней, списки радиусом 26, свайп «Удалить», пружинящие линзы сегментов. Проверка от А до Я — `node site/kcal_test.js [папка-скриншотов]` (139 проверок, сервер фото подменяется; при правке — дописывать сюда новые). Нормы по умолчанию — тренировка 3400 (Б130/Ж105/У485), отдых 2800 (Б125/Ж95/У360), соль ≤ 5 г, дни тренировок Пн Вт Ср Сб (по WHOOP). База `BASE` (продукты) и `DISHES` (популярные блюда ≈) — средние значения на 100 г, последняя цифра — соль. Еда по фото — сервер Тренера (`/api/kcal/pair` код из `/site` → токен, `/api/kcal/photo`, см. `coach/CLAUDE.md`); выбор файла открывается только по нажатию. Иконки — `python3 site/kcal_icons.py`. После правки поднимать `CACHE` в `docs/kcal/sw.js`.
