# Авито (`avito/`)

> Справка Claude по этой папке (загружается сама при работе с её файлами). Общие правила — в корневом CLAUDE.md.

- Бот «Авито» (`avito/`, pm2 `avito-bot`, секреты `/etc/avito-bot.env`, @Avitooo1bot): фото → белый фон (rembg `isnet-general-use` в `avito/.venv`, `avito/photos.py`), описание через `claude -p` (`avito/prompt.md`), «📊 Средняя цена» — до 100 объявлений из поиска avito.ru (`avito/market.py`, разбор HTML; при 429 — Chromium `avito/search.js`; IP сервера play2go и облака Claude Авито блокирует (429 «Доступ ограничен», проверено 12.10) — тогда запасной путь `ai.web_prices`: `claude -p` с WebSearch собирает цены б/у из интернета, в боте помечено «🌐 Примерно»). «📤 Выложить» — набор для подачи (фото, название, цена, описание, кнопка avito.ru/additem), статусы 📝/🟢/✅ (`/ads`, ссылка на объявление или «продал за …» в чат), «💬 Ответ покупателю» (`/buyer`: текст/скрин/голос → `ai.reply_buyer`, торг не ниже «🤝 минимальной цены», мошенники). «💬 Чаты Авито» (`avito/chats.py`, /chats): официальный Messenger API (ключи client_id/secret с avito.ru/professionals/api — бот их удаляет из чата): новые сообщения покупателей → карточка + ответ Claude → «✅ Отправить» в Авито, свой ответ, режимы с подтверждением/автоответ/уведомления, опрос раз в 30 с. Условие Авито: в «Товарах» API мессенджера только на подписке «Максимальный» (иначе 403). Публиковать объявления бот не может (API — платные тарифы). Тесты: `python3 avito/test_avito.py`. Мини-приложение на kit (мята): фото → белый фон + описание → средняя цена с гистограммой; «Выложить», «Продано», ответы покупателям — в чате. Видео и кружок: 1–3 самых чётких кадра как фото, речь — рассказ о вещи.
