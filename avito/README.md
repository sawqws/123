# Авито — объявление за минуту

Telegram-бот: фото вещи → белый фон, продающее описание, средняя цена по похожим объявлениям.

1. **Фото** (до 10, можно альбомом) → фон убирается полностью, вещь по центру белого квадрата 1200×1200 (rembg, модель `isnet-general-use`). Подпись к фото = описание вещи.
2. **Что это** — бренд, размер, состояние, свободным текстом → Claude пишет название (≤ 50 символов, лимит Авито), описание, категорию и задаёт 0–3 уточняющих вопроса.
3. **Число** («3500», «3.5к», «12 тыс») — цена. **Любой другой текст** — правка («короче», «добавь, что есть чек»). Голые числа меньше 300 считаются ответом (размер, память), а не ценой.
4. **📊 Средняя цена** — до 100 объявлений из поиска Авито → Claude отбирает такие же вещи (без чехлов, запчастей, других моделей) → выбросы отбрасываются → медиана, «продать быстро» (25 %), «дороже» (75 %). Результат кэшируется на 6 ч, «🔄 Проверить заново» — по кнопке. Кнопки ставят цену в объявление.
5. **📋 Текст для копирования** — название, описание и цена отдельными сообщениями.

6. **Мини-приложение** (`/app`, кнопка меню «Авито»): последние объявления (фото на белом, название, описание с «Копировать», цена), «Средняя цена» по любому запросу, кнопка цены ставит её в объявление. Сервер — в процессе бота на `127.0.0.1:8793` (`AVITO_PORT`), снаружи `https://avito.<ip-через-дефисы>.sslip.io` (маршрут в Caddy планера) или свой `AVITO_URL`; только владелец, по подписи Telegram. Файлы — `avito/webapp/`. Фото по-прежнему присылаются в чат.

Команды: `/app`, `/new`, `/ad`, `/price`, `/photos`, `/region moskva` (как в адресе avito.ru/moskva; `all` — вся Россия), `/update`.

☰ Меню — квадратик справа от поля ввода (`common/menukb.py`, `KB` в `avito.py`): Новое, Объявление, Все объявления, Чаты Авито, Ответ покупателю, Цена на Авито, Приложение, Режим, Поддержка; ставится при запуске (раз на версию, `kb_ver`) и на /start, кнопка — та же команда.

## Установка

Через «Главного»: «➕ Поставить» → «🛍 Авито» → токен. Или вручную:
```
curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/avito/install.sh | AVITO_TOKEN=123:ABC bash
```
Секреты — `/etc/avito-bot.env`, данные и фото — `avito/data/` (вне git, хранятся последние 15 объявлений), rembg — `avito/.venv`.

## Как устроено

- `avito.py` — бот (только стандартная библиотека), `photos.py` — удаление фона отдельным процессом (память модели ~300 МБ освобождается сразу), `ai.py` — `claude -p`, `prompt.md` — правила текста, `market.py` + `search.js` — поиск на Авито.
- Поиск: страница `www.avito.ru/<регион>?q=…`, разбор карточек `data-marker="item"`. Официального API поиска у Авито нет. Если простой запрос получает 429/«Доступ ограничен» — повтор через Chromium (playwright). Из облака Claude Авито отвечает 429, с сервера не проверено.
- Тесты: `python3 avito/test_avito.py`.

## Выложить и продать

- **📤 Выложить на Авито** — фото альбомом по порядку, название и цена (тап — скопировать), категория, описание отдельным сообщением и кнопка «🌐 Подать на Авито» (avito.ru/additem). «✅ Выложил» или ссылка на объявление в чат → статус 🟢 «на Авито».
- **💬 Ответ покупателю** (`/buyer`) — пришли его сообщение текстом, скриншотом чата Авито или голосом → Claude пишет ответ от Глеба (коротко, на «вы»), кнопка «📋 Скопировать», «🔄 Другой вариант», «💬 Ещё сообщение». Помнит переписку по объявлению (20 реплик), видит описание и заметки.
- **🤝 Торг** — минимальная цена: покупателю не называется, уступки постепенно и не ниже неё. Подозрительное (предоплата, «курьер», код из СМС) — отказ и пометка «похоже на мошенника».
- **💸 Продано** или «продал за 33к» в чат → ✅, `/ads` — все объявления со статусами и суммой продаж, переключение между ними.

## 💬 Чаты Авито (`chats.py`, /chats)

Бот ведёт переписку в Авито через официальный API мессенджера (api.avito.ru):
- новое сообщение покупателя → карточка в Telegram (кто, по какому объявлению, что написал) и готовый ответ Claude
  (учитывает описание, минимальную цену 🤝 и заметки из бота) → «✅ Отправить» — ответ уходит в Авито;
  «🔄 Другой», «✏️ Свой ответ» (текстом или голосом), «📜 Чат» — последние сообщения;
- режимы (/chats → «⚙️ Режим ответов»): ✋ с подтверждением (по умолчанию), 🤖 автоответ (подозрительное —
  предоплата, ссылки, коды — всё равно спрашивает), 🔕 только уведомления;
- проверка новых сообщений раз в 30 с (`AVITO_CHAT_POLL`).

Подключение: /chats → прислать `client_id client_secret` одним сообщением (бот его сразу удаляет); ключи —
avito.ru/professionals/api, хранятся в `avito/data/state.json` (или `AVITO_CLIENT_ID`/`AVITO_CLIENT_SECRET` в env).
**Условие Авито:** по каталогу Авито для разработчиков API мессенджера в «Товарах» доступен только на подписке
«Максимальный»; без неё Авито отвечает 403 — бот так и пишет. Сайт Авито для разработчиков из облака не открывается
(429), условия сверены по копии каталога (OpenAPI от 03.10.2026).
