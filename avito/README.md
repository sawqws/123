# Авито — объявление за минуту

Telegram-бот: фото вещи → белый фон, продающее описание, средняя цена по похожим объявлениям.

1. **Фото** (до 10, можно альбомом) → фон убирается полностью, вещь по центру белого квадрата 1200×1200 (rembg, модель `isnet-general-use`). Подпись к фото = описание вещи.
2. **Что это** — бренд, размер, состояние, свободным текстом → Claude пишет название (≤ 50 символов, лимит Авито), описание, категорию и задаёт 0–3 уточняющих вопроса.
3. **Число** («3500», «3.5к», «12 тыс») — цена. **Любой другой текст** — правка («короче», «добавь, что есть чек»). Голые числа меньше 300 считаются ответом (размер, память), а не ценой.
4. **📊 Средняя цена** — до 100 объявлений из поиска Авито → Claude отбирает такие же вещи (без чехлов, запчастей, других моделей) → выбросы отбрасываются → медиана, «продать быстро» (25 %), «дороже» (75 %). Результат кэшируется на 6 ч, «🔄 Проверить заново» — по кнопке. Кнопки ставят цену в объявление.
5. **📋 Текст для копирования** — название, описание и цена отдельными сообщениями.

Команды: `/new`, `/ad`, `/price`, `/photos`, `/region moskva` (как в адресе avito.ru/moskva; `all` — вся Россия), `/update`.

## Установка

Через «Главного»: «➕ Поставить» → «🛍 Авито» → токен. Или вручную:
```
curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/avito/install.sh | AVITO_TOKEN=123:ABC bash
```
Секреты — `/etc/avito-bot.env`, данные и фото — `avito/data/` (вне git, хранятся последние 15 объявлений), rembg — `avito/.venv`.

## Как устроено

- `avito.py` — бот (только стандартная библиотека), `photos.py` — удаление фона отдельным процессом (память модели ~300 МБ освобождается сразу), `ai.py` — `claude -p`, `prompt.md` — правила текста, `market.py` + `search.js` — поиск на Авито.
- Поиск: страница `www.avito.ru/<регион>?q=…`, разбор карточек `data-marker="item"`. Официального API поиска у Авито нет. Если простой запрос получает 429/«Доступ ограничен» — повтор через Chromium (playwright). Из облака Claude Авито отвечает 429, с сервера не проверено.
- Тесты: `python3 avito/test_avito.py`.
