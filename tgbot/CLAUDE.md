# Секретарь и мост Claude↔Claude (`tgbot/`)

> Справка Claude по этой папке (загружается сама при работе с её файлами). Общие правила — в корневом CLAUDE.md.

- Мост Claude↔Claude (Глеб 18.10): Claude из облака пишет Claude другого человека в Telegram без кнопки — `tg.py send <чат> "[Claude Глеба] …" --auto`, только чаты из `TG_BRIDGE_CHATS` (id через запятую, `/etc/tg-agent.env`; сейчас — чат с мамой, её Claude отвечает с меткой `[Claude мамы]`, читать — `tg.py history <чат>`), только с меткой, без файлов. Остальная отправка — как раньше, с кнопкой.
- Секретарь / агент Telegram (`tgbot/`, pm2 `tg-agent`, **часть Главного — своего бота нет**, @Owntg1241_bot больше не используется): управляет аккаунтом Глеба через Telethon. Claude (`claude -p`, промпт `tgbot/prompt.md`) вызывает `python3 tgbot/tg.py <команда>` → сокет агента → `tgbot/actions.py`. Всё, что меняет Telegram, Глеб подтверждает кнопкой. Расписания — `tgbot/jobs.py` (`tgbot/tmp/jobs.json`). Режим «через Главного» (`TG_MODE=hub`, включается сам, если есть /etc/hub-bot.env): Telegram не опрашивает, обновления получает от hub.py через свой сокет (`_hub`), отвечает токеном Главного, его кнопки — с префиксом `s:` (`botapi.PREFIX`); профиль, команды, аватар и кнопку меню ставит Главный; при первом запуске один раз пишет в старом боте «переехал». `TG_MODE=own` + `TG_AGENT_TOKEN` — снова отдельный бот. Установка без токена: `tgbot/install.sh` (ставит и поднимает сам Главный; HDP `/agent` при Главном только подсказывает). Фото и видео (кадры + речь через `common/media.py`) Claude смотрит через Read (`agent.on_visual`). Папка «Bot» в Telegram Глеба — только его боты, по одному (не типом «все боты», иначе туда попадут BotFather и т. п.): `tg.py botsfolder [--bots u1 u2] [--auto]` — «/start», если бота нет в чатах, и добавить в папку; все боты — из токенов /etc/*.env и /root/bots/*/.env. Сам: после входа Секретаря и после каждой установки/создания бота Главным (`maker.to_folder`). `tg.py newbot <имя> <username> [--auto]` создаёт бота в @BotFather (с `--auto` без подтверждения — так зовёт Главный при «Сделать бота»). Вход в аккаунт — «Войти в аккаунт» в боте: если ключей api_id/api_hash нет, бот сам получает их с my.telegram.org (`tgbot/get_api.py`, код с сайта присылать с пробелами; с VPN сайт отвечает «ERROR»; много кодов подряд — «too many tries» на несколько часов; при любой неудаче бот сам предлагает ручной путь: Глеб создаёт приложение на my.telegram.org без VPN и присылает App api_id и App api_hash одним сообщением — `agent.manual_keys`); ещё вариант — «🖥 Войти как Telegram Desktop» (`agent.DESKTOP`: открытые ключи tdesktop, клиент представляется Desktop’ом; против правил Telegram, есть риск для аккаунта — только по кнопке Глеба после предупреждения; с серверных IP my.telegram.org всегда отвечал «ERROR», проверено 10–12.10) и хранит в tgbot/tmp/settings.json. Секретарь: на «вы», любые вопросы, поиск в интернете, голосовые (`tgbot/voice.py`, faster-whisper base), память `tgbot/tmp/memory.md`. Сессия аккаунта в `tgbot/tmp/` — это полный доступ к аккаунту, никуда не копировать. Оформление: `tgbot/ui.py` (Markdown Claude → HTML Telegram, живой статус, карточки), цветные кнопки Telethon (`style=success|danger|primary`), аватар и баннер — `tgbot/art/` (`make.py` перерисовывает; аватар ставится через аккаунт Глеба после входа). Тесты: `tgbot/.venv/bin/python tgbot/test_tgbot.py`, `tgbot/test_botapi.py` (агент против имитации Bot API), `python3 tgbot/test_get_api.py`.
