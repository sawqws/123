# Сматыватель боксёрских бинтов (Ender-3 V3 KE)

Аналог товара с Озона (наматыватель, 85×80 мм), только лучше:
- **2 детали без поддержек**: корпус и валик с ручкой (у оригинала 4+ деталей и откидная крышка на шарнире).
- **Рулон вынимается без крышки**: тянешь ручку вверх, валик выходит, и рулон выпадает вперёд.
- **Щель-натяжитель** в спинке: бинт идёт через неё ровно и с натягом, поэтому рулон получается плотным и без складок.
- Бинты шириной до 55 мм, длиной **до ~5 м** (у оригинала до 4,5 м).
- Косынки между спинкой и щеками, поэтому корпус не гнётся при намотке.

| Файл | Что это |
|---|---|
| `model.py` | модель (manifold3d), `python3 model.py` → `frame.stl`, `spindle.stl`, `plate.stl` |
| `render.py` | картинки `view_*.png` |
| `ender3v3ke.ini` + `pla.ini` / `petg.ini` | настройки PrusaSlicer под V3 KE (из профиля Creality в OrcaSlicer) |

Нарезка: `prusa-slicer --export-gcode --load ender3v3ke.ini --load pla.ini --center 110,110 plate.stl -o winder_pla.gcode`
- PLA: 220/60 °C, ~2 ч 30 мин, ~91 г; PETG: 240/70 °C, ~3 ч, ~93 г. Слой 0.2, 3 стенки, 15 % gyroid.

## Как мотать
1. Вставь валик в верхнюю щеку, концом бинта (петлёй) — в прорезь вилки, и дожми валик до нижней щеки.
2. По желанию пропусти бинт через щель в спинке (так будет плотнее).
3. Крути ручку. В конце потяни ручку вверх и вынь рулон.
