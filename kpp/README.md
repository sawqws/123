# КПП — пропуск для такси в ЖК

Telegram-бот: присылаешь номер машины из Яндекс Go → бот сразу заказывает разовый пропуск «Такси» в «Домиленд+».

- Номер можно прислать как угодно: `А123ВС777`, «белый Kia Rio, а 123 вс 77», пересланное сообщение, скриншот (читает `claude -p`, если он есть на сервере), видео — запись экрана Яндекс Go (сначала ищем номер в речи, потом `claude -p` смотрит 6 кадров), кружок.
- Голосовое: «а сто двадцать три вэ эс семьсот семьдесят семь» — бот распознаёт речь (`common/media.py`, faster-whisper; ставит `install.sh` через `common/setup.sh`), показывает «🎙 «текст»», и если номера цифрами в тексте нет, `claude -p` переводит продиктованное в `А123ВС777`.
- Карточка с кнопкой «Отменить»; тот же номер в течение 20 минут не дублируется.
- `/passes` — мои пропуска, `/auto` — настройка «Автопропуск» из Домиленда, `/place` — адрес, `/login` — войти заново.
- ☰ Меню — квадратик справа от поля ввода (`common/menukb.py`, `KB` в `kpp.py`): Повторить, Пропуска, Адрес, Автопропуск, Приложение, Режим, Дать доступ, Поддержка; гостю — короткое (Повторить, Пропуска, Приложение, Режим) и только на его /start. Владельцу — при запуске (раз на версию, `kb_ver`) и на /start. Текст кнопки разбирается до поиска номера — пропуск не заказывает.
- `/invite` — ссылка для сестры/семьи (одноразовая, сутки), `/guests` — кто есть. У гостя своя история: последний номер, недавние, режим, список пропусков (на входе владельца видит только свои, владелец — без её). Гость может войти своим Яндекс ID (`/login`) — тогда и вход, и адрес свои; `/logout` — обратно на вход владельца.
- Мини-приложение (`/app`, кнопка меню «КПП»): номер на табличке-госномере (автоформат «А 123 ВС 777», жёлтая — у такси) → «Оформить пропуск»; «Вставить» из буфера, «Скриншот» из Яндекс Go (`POST /api/photo`, тело — картинка → номер в поле), «Повторить» последний; последние пропуска со статусом и «Отменить»; вход через Яндекс по шагам; смена корпуса — нажатием на адрес. Сервер — в процессе бота на `127.0.0.1:8792` (`KPP_PORT`), снаружи `https://kpp.<ip-через-дефисы>.sslip.io` (маршрут в Caddy планера) или свой `KPP_URL`. Пускает только владельца по подписи Telegram (initData не старше суток). Файлы — `kpp/webapp/`.

## Установка

```
curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/kpp/install.sh | bash
```

Нужен новый бот от @BotFather. Секреты — `/etc/kpp-bot.env`, токены Домиленда — `kpp/data/state.json` (вне git, права 600).

## Как устроено

- Вход: Яндекс ID → `POST /auth/yandex/scenario` → JWT Домиленда (как в [ha-domyland](https://github.com/he110/ha-domyland)).
- Пропуск: `POST v2/pass` с `type=1, subType=5` (такси), `passes=[{entityId, regNumber}]`, `arriveDate` в мс. Взято из приложения «Домиленд+» 4.25.5. Если в истории есть прошлый пропуск такси, числа берутся из него.
- Тесты: `python3 kpp/test_kpp.py`.

## Чего нет

Автоматического отслеживания заказа в Яндекс Go: открытого API у Яндекс Go нет.
