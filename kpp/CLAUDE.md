# КПП (`kpp/`)

> Справка Claude по этой папке (загружается сама при работе с её файлами). Общие правила — в корневом CLAUDE.md.

- Бот «КПП» (`kpp/`, pm2 `kpp-bot`, секреты `/etc/kpp-bot.env`): номер такси → разовый пропуск «Такси» в «Домиленд+» (`POST customer-api.domyland.ru/v2/pass`, type=1, subType=5; вход через Яндекс ID → JWT; ссылка входа с redirect_uri на `yx<client_id>.oauth.yandex.ru/auth/finish?platform=ios` — без него Яндекс отдаёт токен сайту lk-new.domyland.ru, и скопировать нечего; вход по телефону на сайте Домиленда — только с reCAPTCHA, боту недоступен). Токены в `kpp/data/state.json` (вне git). Установка: `curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/kpp/install.sh | bash`. Номер принимает текстом, скриншотом, видео (запись экрана Яндекс Go: речь → кадры через `claude -p`), голосом и кружком. Мини-приложение — табличка-госномер с автоформатом, «Вставить», «Скриншот» (`POST /api/photo`, тело — картинка; номер встаёт в поле, пропуск не заказывает), «Повторить» последний. Гости (`/invite`, сестра): у каждого своё — `st["users"][id]` (режим, last, recent, история `mine`), заказывают на вход владельца или свой (`/login`); кто пишет — `use(uid)`/`me()`/`acc()`. Тесты: `python3 kpp/test_kpp.py`. Автоотслеживание Яндекс Go не сделано: нет API.
