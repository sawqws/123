# Студия и Студия сайтов (`studio/`)

> Справка Claude по этой папке (загружается сама при работе с её файлами). Общие правила — в корневом CLAUDE.md.

- «Студия» (`studio/`, pm2 `studio-bot`, секреты `/etc/studio-bot.env`, `STUDIO_TOKEN`): бот, который делает ботов. Идея → 0–3 вопроса кнопками → имя (Глеб даёт сам) → план (чат, мини-приложение, что пишет сам) → «✅ Создать» или правки словами → Claude Code пишет бота на `studio/kit/botkit.py` по заготовке `studio/kit/template/` (мини-приложение у каждого бота всегда; общий дизайн `webapp/kit.css`/`kit.js`), тесты, аватар (`studio/avatar.py`), бот в Telegram в один тап — Managed Bots (кнопка `t.me/newbot/<студия>/<username>`, токен — `getManagedBotToken`; у Студии один раз включить Bot Management Mode в мини-приложении @BotFather), иначе через Секретаря, иначе просит токен, pm2 `bot-<slug>`. Боты в `/root/bots/<slug>/`, список `/root/bots/registry.json` (Главный его видит). Мини-приложения: Caddy планера `apps.<host>` → 8795 → `/b/<slug>/` → порт бота (8800+). Своё приложение Студии — корень `apps.<host>` (адрес в базу и ботам — только когда Caddy отвечает на `/health`; иначе подсказка на главном). Без Секретаря и без Managed Bots токен просится одним шагом сразу в начале сборки (токен во время сборки — не правка). Ставит Главный («➕ Поставить Студия» или `/studio <токен>`); «🛠 Сделать бота» в Главном ведёт в Студию, если она есть. Режим чат/приложение у Студии и всех её ботов — в botkit (`bot.ui_mode()`, `bot.menu(...)`, kit.js «💬 Перейти в чат» → `api/mode`). Тесты: `python3 studio/test_studio.py` (botkit, заготовка, прокси, режим).
- «Студия сайтов» для сестры Глеба (@site_studio_sis_bot, «Site Studio», pm2 `studio-sites`, секреты `/etc/studio-sites.env`, папка `/srv/studio-sites`, порт 8797, адрес `https://web.<host>`): тот же `studio/studio.py` в режиме `STUDIO_MODE=sites` — только сайты (ТЗ → вопросы → план → сборка → 🔒 пароль / 🌍 для всех), без ботов, без /fix и Секретаря; Claude без Bash и читает/пишет только свою папку (`SAFE_DENY` на /root, /etc, /home…) — ключи ботов и сессию Telegram не видит. Владелец — первый /start (Глебу не нажимать). Установка/перезапуск: `bash studio/install_sites.sh [<токен>]`. Тест — класс `SitesOnlyMode` в `studio/test_studio.py`.
