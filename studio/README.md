# 🏗 Студия — бот, который делает ботов

Пишешь идею — Студия уточняет, ты даёшь имя и подтверждаешь план, дальше она всё делает сама.

1. **Идея** — текстом, голосом, можно со скриншотами-примерами.
2. **Вопросы** — 0–3 самых важных, с вариантами-кнопками (или свой ответ, «Пропустить», «Хватит, дальше»).
3. **Имя** — 3 варианта кнопками или своё.
4. **План** — что в чате, что в мини-приложении, что бот пишет сам, @username. «✅ Создать» или правка словами — план переделывается.
5. **Сборка** (3–10 мин, живой статус): заготовка `kit/template` → Claude Code пишет бота на `botkit.py` и прогоняет тесты (упали — чинит сам) → аватар (`avatar.py`: градиент + буква) → бот в Telegram → pm2 `bot-<slug>`.
   Бот в Telegram создаётся в один тап (Managed Bots, Bot API 9.6): пока пишется код, Студия присылает кнопку «⚡ Создать @…» → окно Telegram с готовыми именем и адресом → «Создать» → токен Студия берёт сама (`getManagedBotToken`). Нужно один раз включить у Студии **Bot Management Mode**: @BotFather → Open (мини-приложение) → Студия → Bot Management Mode. Если режим выключен — через Секретаря (`tg.py newbot`), если и его нет — Студия просит токен.
   Нет ни того, ни другого — Студия сразу (пока пишет код) просит одним шагом: @BotFather → /newbot → имя → адрес → токен сюда; токен, присланный во время сборки, подхватывается сам.
6. **Готово**: «▶️ Открыть бота». Правки — просто напиши (или «✏️ Правки»), «↩️ Откатить» — git revert. Пока бот собирается, присланные правки копятся и вносятся сразу после запуска. «✖️ Отмена» недоделанного бота убирает его из «Моих ботов» и с диска.

**Режим «💬 Чат / 📱 Приложение»** встроен в botkit, у Студии и у каждого её бота: первый /start (когда есть https) — «🧭 Как удобнее?», потом /mode, кнопка «⚙️ Режим», в приложении — строка «💬 Перейти в чат» (kit.js → `POST api/mode`). В чате web_app-кнопок нет (кроме /app), в приложении /start короткий: кнопка приложения + 1–2 действия. Главный экран бот собирает через `bot.menu(c, заголовок, строки, buttons=…, quick=…)`.

**Мини-приложение есть у каждого бота** и у самой Студии (вкладки «Новый бот» — весь путь от идеи до запуска, и «Мои боты»: открыть, правка, перезапуск, удаление).

## Устройство

- `studio.py` — сам бот (на том же `botkit`), Claude: `claude -p` (вопросы и план — `STUDIO_TALK_MODEL`, по умолчанию sonnet; код — модель по умолчанию).
- `kit/botkit.py` — библиотека для ботов: Telegram, единый стиль (`card`, `b`, `rows`, цвет кнопок с откатом), `@bot.home/command/button/text/reply/photo/api`, `bot.menu` и режим чат/приложение (`bot.ui_mode()`, `set_mode`, `/mode`, `/app`, api `mode`), `bot.db`, `bot.daily/every`, голосовые и фото (`common/media.py`; фото без обработчика — подпись как текст), `kit.claude()`, сервер мини-приложения с проверкой initData, `bot.testing()` (`t.keyboard` — кнопки целиком). Копируется в папку каждого бота.
- `kit/template/` — заготовка (рабочий пример) + `webapp/kit.css`, `kit.js` — общий дизайн мини-приложений (тема Telegram).
- Боты: `/root/bots/<slug>/` (свой git, `.env` 600, `data/`), список — `/root/bots/registry.json` (Главный тоже его видит: «Все боты», «Доработать», «Удалить»).
- https: Caddy планера `apps.<ip>.sslip.io` → 127.0.0.1:8795 (Студия) → `/b/<slug>/` → порт бота (8800+).

## Установка

Главный: «📂 Все боты» → «➕ Поставить Студия» (Секретарь сам создаст бота) или `/studio <токен>`.
Или: `curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/studio/install.sh | STUDIO_TOKEN=… bash`.
Нужны: Claude Code на сервере (уже вошёл в аккаунт), planner-bot (его Caddy даёт https; пока https не отвечает, Студия пишет об этом на главном экране и работает в чате), для @BotFather — Секретарь или Bot Management Mode (иначе просит токен).

Тесты: `python3 studio/test_studio.py`.


## Сайты
Идея про сайт/лендинг/портфолио → тот же путь (вопросы, имя, план), но Claude пишет статику в `/root/sites/<slug>/` (реестр — `/root/bots/sites.json`, отдельно от ботов). Адрес `https://apps.<ip>.sslip.io/s/<slug>/`. После сборки сайт закрыт (`access: private`, ссылка с ключом `?k=` → cookie). Кнопки: «🔒 Защитить паролем» (окно браузера, пароль 8 символов), «🌍 Выпустить для всех» (с подтверждением), «🔑 Закрыть снова» (новый ключ), «✏️ Правки», удаление. `/sites` — список. Свой домен не подключается (нужна покупка).
