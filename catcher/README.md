# Ловец — юзернеймы Telegram на каналы

Отдельный бот (pm2 `catcher-bot`, секреты `/etc/catcher-bot.env`, переменная `CATCHER_TOKEN`). Ловит крутые юзернеймы и ставит их на каналы Глеба.

## Что умеет

- **Имена**: прислать `@имя` (или `t.me/имя`, можно списком). Свободно → занимает сразу. Занято → следит по кругу и занимает, как освободится, пишет в чат. Продаётся на Fragment или недопустимо → говорит и не следит (такие имена ловятся только покупкой на Fragment).
- **🎲 По пожеланиям**: выбор длины (5 / 6–7 / 8–10 / любая), стиля (одно слово, два слова, слово + цифра, как имя, любой), темы, «только буквы» и сколько поймать (1 / 3 / 5 / 10). Бот сам придумывает кандидатов (Claude через `claude -p`, без него свой генератор), проверяет их по кругу и занимает свободные, пока не наберёт нужное число. Пожелания и ловля — в чате (`/wish`) и в приложении (вкладка «Пожелания»).
- **✨ Идеи** (`/ideas`): имена на тему и что из них свободно сейчас, кнопки «Занять» и «Следить».
- **⚙️ Настройки** (`/settings`): интервал проверки (3–60 с), куда ставить имя: новый канал (по умолчанию, запасной канал создаётся один раз) или свой канал без юзернейма.
- Мини-приложение: вкладки «Имена», «Пожелания», «Идеи», настройки. Сервер в процессе бота на `127.0.0.1:8796` (`CATCHER_PORT`), снаружи `https://catcher.<ip-через-дефисы>.sslip.io` (маршрут в Caddy планера) или свой `CATCHER_URL`. Пускает только владельца по подписи Telegram.
- 🛠 Поддержка (`/fix`) как у всех ботов.

## Как устроено

Занять юзернейм через Bot API нельзя, это умеет только аккаунт человека. Поэтому проверка и захват идут через **Секретаря** (`tgbot/`, сокет `tgbot/tmp/agent.sock`): команды `username` (проверка), `grab` (занять на канал), `reserve` (запасной канал), `mychannels` в `tgbot/actions.py`, CLI `python3 tgbot/tg.py username|grab|reserve|mychannels`. Секретарь не вошёл в аккаунт (`/login` в Главном) — Ловец это говорит и ждёт, раз в час напоминает.

- Проверка: `channels.CheckUsername` с пустым каналом. Статусы: free, taken, fragment (`USERNAME_PURCHASE_AVAILABLE`), invalid, flood (пауза на `FloodWait`).
- Захват: `channels.UpdateUsername` на канал. Если канал не указан, создаётся новый.
- Лимит Telegram: 10 публичных каналов на аккаунт (`CHANNELS_ADMIN_PUBLIC_TOO_MUCH`). Имя ставится на «паузу», в списке кнопка «Снова следить».
- Ловля по пожеланиям и слежение чередуются в одном фоновом цикле (`Watcher`). Интервал по умолчанию 5 с.
- Секретарь подтверждения не спрашивает (`auto`): Глеб сам дал список имён или пожелания.

## Ограничения

- Точных лимитов частоты запросов у Telegram нет в документации. Чаще 3 с не проверять; при `FloodWait` бот сам делает паузу.
- Освободившееся имя может занять кто-то быстрее. Гарантии нет.
- Автоматизация через пользовательский аккаунт формально против правил Telegram; риск для аккаунта точно не оценён.

```

```
