# Ловец (`catcher/`)

> Справка Claude по этой папке (загружается сама при работе с её файлами). Общие правила — в корневом CLAUDE.md.

- «Ловец» (`catcher/`, pm2 `catcher-bot`, секреты `/etc/catcher-bot.env`, `CATCHER_TOKEN`): ловит юзернеймы Telegram на каналы Глеба. Имена: `@имя` (списком) → свободно — занимает сразу, занято — следит по кругу и занимает, как освободится, Fragment/invalid — говорит и не следит. «🎲 По пожеланиям» (`/wish`): длина, стиль, тема, «только буквы», сколько поймать → бот сам придумывает кандидатов (`claude -p`, без него свой генератор), проверяет и занимает свободные. «✨ Идеи» (`/ideas`), «⚙️ Настройки» (интервал 3–60 с, новый или свой канал без юзернейма). Занять имя может только аккаунт человека, поэтому проверка и захват идут через Секретаря (`tgbot/actions.py`: `username`, `grab`, `reserve`, `mychannels`; CLI `tg.py username|grab|reserve|mychannels`, `auto` — без подтверждения). Лимит Telegram — 10 публичных каналов (имя встаёт на «паузу»). Мини-приложение `catcher/webapp` (порт 8796, `catcher.<host>` через Caddy планера). Ставит Главный: `/catcher` или `curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/catcher/install.sh | bash`. Тесты: `python3 catcher/test_catcher.py`. Подробно — `catcher/README.md`.
