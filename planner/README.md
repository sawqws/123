# Ритм — Telegram-бот-планер

Планер дня, недели и месяца с целями и заметками. Главное — приложение внутри Telegram (кнопка «Планер» у поля ввода).

**Приложение**
- **День** — полоса недели, прогресс дня, просроченное (перенос в одно касание), цели в фокусе, план по времени, быстрое добавление.
- **Неделя** — 7 дней с галочками, цели недели, «Без даты».
- **Месяц** — календарь с точками задач, план выбранного дня, итог месяца, цели месяца.
- **Цели** — на неделю / месяц / год / без срока: эмодзи, цвет, «зачем мне это», дедлайн, шаги (прогресс считается сам) или ручной прогресс, **заметки** лентой, «Цель достигнута» с конфетти, архив.
- Задачи: время, повтор (каждый день, будни, свои дни), напоминание, «важное», привязка к цели, заметка.
- Тёмная и светлая тема как в Telegram, вибрация, свайпы, кнопка «назад».

**Чат**
- Просто напиши задачу: «завтра в 18:00 тренировка», «по пн и ср английский в 19:00», «12.10 контрольная!».
- /today, /tomorrow — план с галочками и листанием дней; /week; /goals; /export — копия данных файлом.
- Утром план на день и цели, вечером итоги с кнопкой «перенести несделанное на завтра», в воскресенье — итог недели.
- Напоминания перед задачами с кнопкой «Сделано».

**Устройство**: `planner.py` (бот, веб-сервер на 127.0.0.1, расписание; https для приложения — Caddy на этом сервере, порты 80/443, сертификат Let's Encrypt на `1-2-3-4.sslip.io` и на IP; запасной путь — туннель cloudflared; `/status` — что с адресом), `store.py` (SQLite, `planner/data/`, ежедневные копии в `data/backups`), `parse.py` (разбор текста), `webapp/` (приложение без сборки). Только стандартная библиотека Python.

**Установка** (от root, можно на тот же сервер, где HDP-бот):
```
curl -fsSL https://raw.githubusercontent.com/sawqws/123/main/planner/install.sh | bash
```
Спросит токен нового бота от @BotFather. Логи: `pm2 logs planner-bot`.

**Тесты**: `python3 planner/test_planner.py`.
