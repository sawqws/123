# Предпочтения по скиллам — твой персональный конфиг

> Этот файл читается PM-скиллом ПЕРЕД скорингом. Любимые скиллы получают +1 к match score и помечаются ⭐ в выводе, обязательные — 🔒 и ставятся на верх шортлиста.
>
> **Это шаблон.** Из коробки он почти пустой — заполни под себя. PM не выдумывает предпочтения: сюда попадает ТОЛЬКО то, что ты явно одобрил.
>
> **Как обновлять:** скажи в чате «PM, запомни что я люблю X для Y» / «добавь в избранное X» / «PM, больше не предлагай Z» — Claude дополнит этот файл и отметит дату в «Истории изменений».
>
> **Формат:** одна строка = одно правило. Контекст — в скобках.

---

## 🔒 ОБЯЗАТЕЛЬНЫЕ скиллы (must-use, не предмет выбора)

## ⭐ Любимые скиллы

Только то, что ты явно назвал любимым. Новый, ни разу не опробованный скилл сюда НЕ добавляется.

*(Пусто — заполнится по мере того как ты будешь говорить «о, это удобно».)*

---

## 🎯 Контекстные предпочтения по проектам

*(Пусто — добавляется когда ты явно скажешь «для проекта X использую Y».)*

Сюда можно вписать свои проекты, чтобы PM узнавал контекст задачи:

<!--
- **<Проект A>** — <что это, какой стек, какие особенности>
- **<Проект B>** — <...>
-->

PM использует названия проектов только чтобы понять контекст — он НЕ выдумывает, какие скиллы ты «должен» под них применять.

## 🚫 Анти-скиллы

Скиллы, которые PM НЕ предлагает (если задача их прямо не требует).

*(Пусто — добавляется когда скажешь «PM, больше не предлагай X», с причиной.)*
