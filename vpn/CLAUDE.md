# VPN для домашнего роутера (Глеб, 25.10)

Роутер Глеба — Keenetic Peak (KN-2710), стабильная KeeneticOS 5.x. VPN-сервер — на сервере ботов (Германия), AmneziaWG
с параметрами 1.0 (Jc/Jmin/Jmax/S1/S2/H1–H4): их KeeneticOS ≥ 4.3.4 сама берёт из .conf («Загрузить из файла»).
Параметры 1.5/2.0+ (S3/S4, I1–I5, диапазоны H) не добавлять — стабильная прошивка их не знает.

- Установка/новый клиент: `bash vpn/install.sh [имя]` (на сервере — `/root/vpn-src/`, через `hub/remote.py sh`).
  Интерфейс `awg0`, UDP 47811, сеть 10.66.66.0/24, NAT через iptables в PostUp/PostDown. Ботов не трогает.
- Конфиги клиентов: `/root/vpn/clients/<имя>.conf` (секреты — не в репозиторий, не в Brain). Глебу — файлом в чат.
- Выключить на время: `systemctl stop awg-quick@awg0`; включить — `start`. Статус: `awg show awg0`.
- Откат полностью: `bash /root/vpn-src/uninstall.sh` — убирает пакеты, поставленные install.sh (список
  `/root/vpn/installed-by-vpn.txt`), PPA и пересылку. Ключи остаются в `/root/vpn/saved` → повторный install даёт тот же
  конфиг роутера. `--purge` — стереть и их.
- На роутере откат: выключить подключение в «Интернет → Другие подключения».
